## Found along the way

- **Claude Code 2.1.306 eval harness:** `!` load lines fail inside `claude plugin eval` (above). Normal sessions are
  unaffected. Re-check on the next CLI release; until then, run the slash and smoke suites on 2.1.303
  (`npx @anthropic-ai/claude-code@2.1.303 plugin eval …`).
- **Two CLI versions at once share one login.** Running a 2.1.303 and a 2.1.306 eval at the same time revoked the
  OAuth token for one of them mid-run (3 rewrite runs failed with "OAuth token revoked"). Run evals one CLI at a time.
- **`claude plugin eval` takes one `--case`;** a second one is ignored. Run one tag per invocation too: the one
  run with two `--tag` flags loaded a single case (before the token clash stopped it), so its filter wasn't checked.
- **A narrow `Bash(python3 *)` grant isn't enough for the skills' own runs:** the model appends `; echo "exit=$?"`,
  which `dontAsk` mode denies. The smoke cases grant `Bash`.
- **The eval home folder holds a `.git`,** so a case's project root resolves above its working folder unless the
  case saves `.plainspoken/config.toml` first; the smoke cases that write reports do.
